EDUPLAN AI — PENGGABUNGAN TANPA DESAIN ULANG
==========================================

Gunakan paket ini menggantikan paket desain ulang sebelumnya.

FILE UTAMA
- index.html
- app.js
- style.css

PERUBAHAN STRUKTUR SAJA
1. Isi EduNotify asli dipindahkan ke app.js, dengan toast, ikon, tombol
   tutup, progress bar, durasi, jeda hover/fokus, dan antrean dialog.
2. Sebelas fungsi pengganti dari notification-ui.js memakai implementasi
   aslinya dalam satu deklarasi, bukan menimpa versi lain setelah loading.
3. CSS notifikasi asli ditambahkan setelah stylesheet aplikasi, mengikuti
   urutan cascade sebelumnya. Nilai warna, ukuran, dan animasi dipertahankan.
4. Contoh rujukan memakai getReferenceExample(type) pada generator aktif.
5. Pembatas fungsi dan daftar fungsi ditambahkan. CSS diberi baris terpisah.
6. Penanda debugging TES REVISI dan Arom Kobama Tes tidak dipakai; identitas
   pengembang kembali Arom Kobama.

FITUR YANG DIPERTAHANKAN
Login email, sesi, dashboard, kategori generator, editor, simpan, ekspor
PDF/Word/TXT, salin, filter dan halaman riwayat, favorit, sampah/pulihkan,
profil, pengguna, provider, kuota, tes koneksi, log, panduan, menu mobile,
tema, kredit pengembang, avatar, loading, serta notifikasi/dialog asli.
URL API dan nama action backend tidak diubah. Tidak ada perubahan Code.gs.

CARA PASANG
1. Cadangkan proyek lama.
2. Ganti ketiga file utama secara bersamaan, jangan ditambahkan di bawah
   kode lama dan jangan dicampur dengan paket desain ulang sebelumnya.
3. Gunakan index.html dari paket ini. File HTML hanya memanggil app.js
   dan style.css; notification-ui.js dan notification-ui.css tidak dipanggil.
4. Setelah memasang paket ini, kedua file notifikasi terpisah boleh dihapus
   dari proyek aktif atau dipindahkan ke folder cadangan.
5. Muat ulang aplikasi dan buka kembali generator. Uji notifikasi dan
   dialog menggunakan alur aplikasi. Hati-hati: konfirmasi simpan tetap
   benar-benar menyimpan ke backend jika disetujui.

CONTOH MENU
10 kode menu yang diketahui punya contoh khusus: rpp, modul_ajar, atp,
cp_rujukan, tp, kktp, lkpd, prota, promes, distribusi_tp.
Menu katalog lain tetap tersedia dan mendapat contoh cadangan; tambahkan
kode menu sebenarnya ke getReferenceExample untuk contoh khusus lain.
Contoh TP dan data hanya ilustrasi. CP resmi harus berasal dari sumber
terverifikasi. Tidak ada data pribadi peserta didik dalam contoh.

PENGUJIAN DAN BATASAN
Pemeriksaan sintaks node --check; pengujian terisolasi pembentukan
11 formulir, 2 jenis toast, struktur dialog asli, tombol batal/setuju,
identitas login dan kedua avatar. CSS diperiksa dengan parser.
Fungsi dasar yang tidak diganti dibandingkan dengan kode dasar; fungsi
notifikasi yang digabung dibandingkan dengan implementasi yang disalin.
Belum diuji end-to-end terhadap server nyata atau dibandingkan screenshot
browser. Tidak menjamin identik piksel-per-piksel di setiap perangkat.
Login tetap tanpa verifikasi kepemilikan email; hanya untuk lingkungan
tepercaya. Penggabungan ini tidak menambah autentikasi atau mengubah izin.
